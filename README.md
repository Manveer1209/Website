# Keshav Uppal

> My personal website built with Next.js, Tailwind CSS, and Framer Motion.

A minimal OLED-black, terminal-inspired website that showcases my projects, certifications, and journey as a developer while reflecting my passion for Linux and clean engineering.

## 🌐 Live Website

**https://keshavuppal.vercel.app**

## ✨ Features

- OLED-black minimal design
- Terminal-inspired interface
- Custom animated cursor
- Linux-style boot sequence
- Responsive design
- GitHub integration
- Certifications section
- Smooth Framer Motion animations
- SEO optimized
- Built with accessibility in mind

## 🛠 Tech Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/Manveer1209/<repository-name>.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
